# DOC-01 Portfolio Draft

## Проект

Telegram Booking Bot (MVP) для онлайн-записи клиентов на услуги.

## Задача

Сделать рабочий MVP для малого сервиса (например, студии красоты), где клиент записывается через Telegram, а менеджер получает уведомления и контролирует заявки.

## Что реализовано

- Telegram-бот с FSM-сценарием записи.
- Генерация слотов с учетом рабочего времени, длительности услуги и буфера.
- Защита от конфликтов слотов на уровне БД.
- `Мои записи` и отмена в боте.
- Admin API: услуги, слоты, записи, смена статусов.
- Worker с напоминаниями `24h/2h`, ретраями `5/15/30`, статусом `failed`.
- Health-check, JSON-логи, базовые метрики.
- Unit, integration и e2e smoke тесты.

## Технологии

- Python, aiogram, FastAPI
- PostgreSQL, Redis
- SQLAlchemy, Alembic
- Docker Compose
- GitHub Actions (CI/CD + deploy/rollback скрипты для staging)

## Результат MVP

- Клиент проходит путь записи от выбора услуги до подтверждения.
- Менеджер получает события о новой/отмененной записи.
- Критический путь покрыт автотестами и пайплайном.

## Следующие шаги (P1/P2)

- Перенос записи и waitlist.
- CRM-интеграции.
- Онлайн-оплата.
- Мультифилиальность и календари мастеров.
