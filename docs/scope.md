# AN-01 Scope (MVP Demo)

Дата фиксации: 2026-03-03

## Ниша демо

Студия красоты (запись на базовые услуги).

## Услуги MVP (6 шт.)

| Код | Услуга | Длительность | Цена (BYN) |
|---|---|---:|---:|
| `svc_haircut_women` | Женская стрижка | 60 мин | 60 |
| `svc_haircut_men` | Мужская стрижка | 45 мин | 40 |
| `svc_coloring_roots` | Окрашивание корней | 90 мин | 110 |
| `svc_manicure_classic` | Маникюр классический | 60 мин | 50 |
| `svc_brows_shape` | Коррекция бровей | 30 мин | 30 |
| `svc_makeup_day` | Дневной макияж | 75 мин | 90 |

## Рабочие часы (по умолчанию)

- Понедельник-пятница: `09:00-20:00`
- Суббота: `10:00-18:00`
- Воскресенье: выходной
- Буфер между слотами: `10` минут (`SLOT_BUFFER_MIN=10`)
- Таймзона: `Europe/Minsk` (локальный запуск) / может быть переопределена через `TIMEZONE`.

## Ограничения MVP

- Один филиал и единый календарь.
- Без онлайн-оплаты.
- Без переноса записи (только отмена и новая запись).
- Без CRM-интеграций.

## Критерий готовности AN-01

- Скоуп зафиксирован в этом файле.
- Указаны ниша, 5-7 услуг и рабочие часы.
